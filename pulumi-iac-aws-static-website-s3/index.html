About me

I'm a software engineer who owns features from the database schema to the UI. I like working at the seam between frontend and backend, designing APIs that keep interfaces simple.

On the frontend I use React on the web and React Native on mobile, sharing types and logic across platforms. On the backend I use Node.js when iteration speed matters and Go when throughput does, with PostgreSQL as the source of truth and AWS for infrastructure.

I care about the unglamorous parts: migrations that roll back cleanly, alerts that fire before users notice, and CI pipelines fast enough that nobody skips them.
